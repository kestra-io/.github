<p align="center">
Kestra unifies <b>scheduled</b> and <b>event-driven</b> automation behind a declarative, language-agnostic interface. Build reliable workflows for data, AI, and infrastructure — in code or from the UI, in just a few lines of YAML.

## Why Kestra?

- **Everything as Code, and from the UI** — keep workflows as code with Git version control, even when building them visually.
- **Event-driven & scheduled** — automate both real-time event-driven and scheduled workflows from a simple declarative interface.
- **Language-agnostic** — run scripts in Python, Node.js, R, Go, Shell, and more, with hundreds of plugins.
- **Built for scale** — designed to handle millions of workflows, with high availability and fault tolerance.
